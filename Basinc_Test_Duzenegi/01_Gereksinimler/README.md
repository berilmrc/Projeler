# 1. Gereksinimler

Bu bölüm, test düzeneğinden ne beklendiğini tanımlar.

## İşlevsel gereksinimler

| No | Gereksinim |
|---|---|
| G-01 | Sistem, atmosferin hem altında hem üstünde istenen basıncı üretebilmelidir. |
| G-02 | Üretilen basınç, hassas bir referans sensörle ölçülmelidir. |
| G-03 | Basınç, ayarlanan değerde sabit tutulabilmelidir. |
| G-04 | Ölçümler zaman bilgisiyle birlikte bilgisayara kaydedilmelidir. |

## Teknik gereksinimler

| No | Gereksinim |
|---|---|
| T-01 | Referans sensör endüstriyel bir haberleşme protokolüyle okunmalıdır. |
| T-02 | Basınç kaynağı yazılımla kontrol edilebilmelidir. |
| T-03 | Kayıtlar analiz için düz metin / CSV biçiminde olmalıdır. |
| T-04 | Sistem tek bir 12 V DC kaynaktan beslenmelidir. |
| T-05 | Tüm bileşenlerin toprağı tek bir noktada birleşmelidir. |
